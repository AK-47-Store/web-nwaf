# N2flix

متجر رقمي لعرض المنتجات، مع إكمال الطلبات عبر واتساب.

## لوحة الإدارة والحفظ المباشر

- حفظ المنتجات والصور والترحيب وإعدادات واتساب وبيانات الدفع مباشرة من لوحة الإدارة.
- تُحمّل الصفحة المنشورة أحدث نسخة من الكتالوج السحابي عند فتحها؛ لا يحتاج تعديل المنتجات إلى رفع ملفات أو إنشاء commit في GitHub.
- يلزم إعداد Supabase مرة واحدة. اتبع [دليل الإعداد بالعربية](SUPABASE-SETUP-AR.md)، ثم أضف رابط المشروع ومفتاحه العام في `cloud-config.js`.
- استخدم مفتاح Supabase العام (`publishable` أو `anon`) فقط في المتصفح. لا تضع `secret` أو `service_role` أو كلمة مرور قاعدة البيانات في ملفات الموقع.
- تمنح سياسات Row Level Security للزوار قراءة الكتالوج والصور، وتسمح بالكتابة فقط لحساب يحمل دور `store_admin`.
- إذا لم يُربط Supabase، تحفظ الإدارة مسودة على هذا الجهاز وتعرض تنبيهًا واضحًا بأنها غير منشورة.

## المتجر

- لا توجد حسابات عملاء أو صفحة طلبات أو استيراد وتصدير JSON للطلبات.
- الشراء المباشر والسلة يفتحان رسالة واتساب تتضمن المنتجات والكميات والسعر التقديري.
- صفحة **بيانات الدفع** مستقلة؛ لا تظهر بياناتها في السلة أو رسالة الطلب.
- لا ينفذ الموقع دفعات ولا يؤكدها.
- الألوان والهوية البصرية لـ N2flix سوداء ومحايدة.
