# N2flix

متجر رقمي ثابت يعمل على GitHub Pages بهوية سوداء ودرجات رمادية وبيضاء. يمكن للعميل تجهيز الطلب ثم اختياريًا إرساله للمراجعة عبر واتساب أو تيليجرام. لا ينفذ الموقع الدفع ولا يؤكد الطلب تلقائيًا.

لوحة الإدارة تحفظ مسودات المتجر في المتصفح وتتيح إدارة المنتجات والطلبات المستوردة والعملاء المحليين ورسالة الترحيب وقنوات التواصل وقوالب الرسائل وتعليمات التحويل. الطلبات والعملاء لا يتزامنون بين الأجهزة؛ لمراجعة طريقة النشر والحدود الأمنية راجع دليل الموقع والإدارة.
