# N2flix

موقع متجر ثابت يدعم إرسال الطلب اختياريًا إلى واتساب أو تيليجرام. ألوان الواجهة سوداء وحمراء، وتظهر رسالة «ارحبوو» للزوار عند دخول الموقع ويمكن تعديلها من الإدارة.

الإدارة المحلية مخصصة لقائمة المنتجات ورسالة الترحيب، دون حساب أو كلمة مرور. للنشر عبر GitHub Pages راجع [دليل الموقع والإدارة](START-HERE-V2-AR.md).
