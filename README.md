# N2flix

متجر رقمي ثابت لعرض المنتجات وفرزها ومراجعة تفاصيلها. يرسل العميل اختياره مباشرة إلى واتساب برسالة جاهزة للمراجعة. لا توجد حسابات عملاء أو صفحة طلبات أو إدارة لطلبات JSON.

صفحة **بيانات الدفع** مستقلة وقابلة للتحرير من الإدارة؛ لا تُدرج معلوماتها تلقائيًا في السلة أو رسالة الطلب. يؤكد المتجر التوفر والسعر وطريقة الدفع داخل واتساب، ولا ينفذ الموقع دفعة أو يؤكدها.

## لوحة الإدارة

- إدارة المنتجات والصور والتصنيفات والأسعار.
- تخصيص الترحيب: ثمانية تصاميم وثمانية خيارات حركة، مع معاينة قبل الحفظ.
- ضبط رقم واتساب وقوالب الشراء والاستفسار والدعم والدفع.
- تحرير محتوى صفحة بيانات الدفع.
- تُحفظ المسودات في متصفح الإدارة. استخدم **تصدير تحديث الموقع ZIP** ثم ارفع الملفات الناتجة إلى مستودع GitHub لنشرها.

GitHub Pages استضافة ثابتة؛ لا يوفر هذا المشروع قاعدة بيانات مشتركة أو تحققًا خادميًا لحساب الإدارة. لا تحفظ بيانات العملاء أو كلمات المرور أو تفاصيل دفع حساسة في ملفات المستودع.
