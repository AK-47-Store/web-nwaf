كيف أنشر التعديلات؟
  1. احفظ المنتج ثم افتح معاينة المسودة.
  2. اضغط «تصدير تحديث الموقع ZIP» وفك ضغط الملف.
  3. ارفع محتوياته إلى جذر مستودع الموقع في GitHub واستبدل الملفات ذات الأسماء نفسها.
  4. انتظر اكتمال نشر GitHub Pages ثم افتح الموقع مجددًا. الصور تحتاج مجلد assets/uploads المصدّر معها.
